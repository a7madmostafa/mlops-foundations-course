Module 1 · The Software Foundation

From a fragile notebook to a real ML project — structure, dependencies, configuration, robustness, tests. Five lessons, each ending with the flight-delay project visibly better and still runnable.

Start here

This is the foundation of the whole course — every later module assumes the project you build in these five lessons. Begin with L1.1, where you build your own baseline notebook and name the problems the rest of the course fixes.

L1.1 Your Starting Point: The Flight Delay Notebook Get to know the flight-delay data, build your own baseline notebook, then read it like an engineer and name the problems that make it dangerous in production. → L1.2 From Notebook to Structured ML Project Turn the notebook into an installable src/ project — importable pipeline modules, uv + lockfile, and configurable paths. → L1.3 Clean, Typed, Consistent Code Move raw-time feature derivation into the saved model, clarify responsibilities, and enforce formatting, linting, and type checks. → L1.4 Robustness & Logging Make expected input failures clear, preserve tracebacks for bugs, and replace prints with timestamped, leveled console logs. → L1.5 Automated Testing Test units, command boundaries, class-1 prediction semantics, and the raw-to-loaded-model chain with pytest. →
